Day26 - Spring Task定时任务与WebSocket双向通信

一、Spring Task 定时任务

1.1 概述

Spring Task 是 Spring 框架提供的任务调度工具，可以按照约定的时间自动触发执行某段代码逻辑。

核心用途：凡是需要定时处理的场景都可以使用，例如信用卡还款提醒、未支付订单超时处理等。

1.2 cron 表达式

cron 表达式是一个字符串，用于定义任务触发的时间。

  • 构成规则：分为 6 或 7 个域，由空格分隔，含义依次为：秒、分、时、日、月、周、年（可选）

  • 日和周一般不同时设置具体值，其中一个用 ? 表示不关心

  • 实际开发中通常使用在线生成器自动生成，无需手写

常用通配符速查：

通配符 含义
* 所有值
? 未说明的值，不关心
- 指定范围
, 附加一个可能值
/ 前为开始时间，后为每次递增值

常用示例：

需求 cron 表达式
每 5 秒执行一次 0/5 * * * * ?
每分钟执行一次 0 * * * * ?
每天凌晨 1 点执行 0 0 1 * * ?
每天 5-15 点整点触发 0 0 5-15 * * ?

二、WebSocket 双向通信

2.1 与 HTTP 的对比

WebSocket 是基于 TCP 的网络协议，实现了浏览器与服务器的全双工通信。一次握手后即可创建持久性连接，并持续双向传输数据。

对比项 HTTP WebSocket
通信方向 单向，请求-响应模式 双向，双方均可主动发送
连接模式 短连接，一次请求对应一次连接 长连接，建立后持续保持
服务端推送 不支持，服务端无法主动发消息 支持，服务端可随时推送
底层协议 TCP TCP

WebSocket 不能完全取代 HTTP：维护长连接有成本，浏览器支持程度不一，且受网络波动影响需要处理重连，只适合特定实时场景。

2.2 应用场景

  • 网页聊天（即时通讯）

  • 视频弹幕

  • 体育比赛 / 股票行情实时更新

  • 外卖系统的来单提醒和客户催单

今日总结

模块 核心要点
Spring Task 定时任务框架；@EnableScheduling 开启调度，@Scheduled(cron=...) 标记方法；cron 表达式用在线生成器
