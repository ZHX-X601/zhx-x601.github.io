Day29 - Redis入门与Java客户端

一、Redis 简介

1.1 什么是 Redis

Redis（Remote Dictionary Server）是一个基于内存的键值型 NoSQL 数据库。数据以 key-value 形式存储，value 支持字符串、数值、JSON 等多种结构。

1.2 SQL 与 NoSQL 的对比

维度 SQL（关系型数据库） NoSQL（非关系型数据库）
数据结构 结构化（表、字段、约束严格） 非结构化，形式松散自由
关联关系 表之间存在关联（外键） 无关联关系，靠业务逻辑维护
查询方式 统一 SQL 语法 各数据库查询语法差异大
事务 满足 ACID 不保证严格 ACID，遵循 BASE
存储方式 基于磁盘，IO 较多 基于内存，读写速度快

ACID vs BASE：ACID 强调强一致性（原子性、一致性、隔离性、持久性）；BASE 强调基本可用、软状态、最终一致性，用一致性换取高可用和高性能。

三、Redis 常见命令

Redis 是 key-value 数据库，key 一般为 String，value 支持多种数据结构。常见的 5 种数据结构：

类型 说明 典型命令
String 普通字符串，也可存整数/浮点 SET、GET、INCR、SETEX、SETNX
Hash 散列，类似 HashMap，可对单个字段操作 HSET、HGET、HGETALL
List 双向链表，有序可重复 LPUSH、RPUSH、LRANGE
Set 无序不可重复，支持交/并/差集 SADD、SMEMBERS、SINTER
SortedSet 可排序的 set，带 score ZADD、ZRANGE

通用命令适用于所有类型：KEYS、DEL、EXISTS、EXPIRE、TTL。

key 支持层级结构，用 : 分隔，如 heima:user:1，可视化工具会以目录形式展示。

四、Redis 的 Java 客户端

4.1 三种客户端对比

客户端 特点
Jedis 直连 Redis，API 与命令一一对应；线程不安全，多线程需为每个线程创建独立实例；推荐配合连接池使用
Lettuce 基于 Netty，线程安全，支持响应式编程
Spring Data Redis 对 Jedis 和 Lettuce 做了抽象封装，提供统一的 RedisTemplate API

五、RedisTemplate 的序列化器

5.1 为什么要配置序列化器

RedisTemplate 默认使用 JDK 序列化，写入 Redis 的数据可读性差且内存占用大。需要自定义序列化方式：key 用 String，value 用 JSON。

讲义中使用的 GenericJackson2JsonRedisSerializer 在新版 Spring Data Redis 中已废弃，应改用 RedisSerializer.json()。

5.2 新版序列化器配置

key 和 hashKey 用 RedisSerializer.string()，value 和 hashValue 用 RedisSerializer.json()。

六、手动序列化

6.1 为什么手动序列化

JSON 序列化器会在 value 中写入类的全限定名（用于反序列化时识别类型），带来额外内存开销。为了节省内存，可以使用 StringRedisTemplate + 手动 JSON 序列化，value 中只存纯 JSON 字符串。

6.2 StringRedisTemplate + ObjectMapper

StringRedisTemplate 是 RedisTemplate 的子类，key 和 value 默认都使用 String 序列化，省去了自定义序列化器的步骤。

模块 核心要点
Redis 简介 基于内存的键值型 NoSQL 数据库；SQL 满足 ACID 存磁盘，NoSQL 遵循 BASE 存内存
安装 CentOS 7 下解压 → 编译安装 → 修改 redis.conf → 配置 systemd 自启
数据结构 String、Hash、List、Set、SortedSet 五种；key 用 : 做层级分隔
Java 客户端 Jedis 线程不安全需配合连接池；Lettuce 线程安全；Spring Data Redis 统一封装为 RedisTemplate
新版配置 Spring Boot 3.x 配置路径变为 spring.data.redis
序列化器 默认 JDK 序列化可读性差；自定义 key 用 string、value 用 json；新版用 RedisSerializer.json()
手动序列化 用 StringRedisTemplate + ObjectMapper 手动序列化，避免写入 class 信息，节省内存
