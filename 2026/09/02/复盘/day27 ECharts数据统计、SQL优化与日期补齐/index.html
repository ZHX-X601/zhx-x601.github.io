  1. 前端技术Apach ECharts

    1. 营业额统计
    2. 用户统计
      1. 分组查询,返回List<Map>,遍历,构造vo所需list
    3. 订单统计
      1. 查询begin之前注册的用户总数
      2. 分组查询,查询日期与每日新增,返回List<Map>
      3. 遍历累加获得每日用户总数,构造vo所需list
    4. 订单统计
      1. 本来的思路:两次查询得到订单数与有效订单数
      2. 从ai学到了sum(case when status=5 then 1 else 0 end),实现一次查询
    5. 销量排名
      1. 学到了orders.order_time >= #{begin} and orders.order_time < #{endPlus1}比date(order_time) between #{begin} and #{end}更优
      2. 因为前者可以为order_time建立索引,提高查询效率,但是后者不能
